# Ramadan App

Ramadan App is a full-stack Ramadan competition platform designed to encourage consistency in good habits and daily achievements during Ramadan. Users can complete tasks, earn or lose points, answer daily questions, and compete on a real-time leaderboard.

The project was developed as an AI-assisted application using React Native, Node.js, Express, and PostgreSQL. The system supports both mobile and web environments, with deployment versions available for browsers and andriod application (apk) builds.

## Features

* User authentication system
* Daily tasks with dynamic point calculation
* Real-time leaderboard
* Daily questions and rewards
* Streak and achievement system
* Activity tracking and logs
* Admin dashboard and task management
* Notification system
* Ramadan-themed interface

## Technical Details

The application was built with a focus on scalability and flexibility compared to the first version of the Ramadan website. The backend uses PostgreSQL for data storage and Express.js for API handling, while the frontend is developed using React Native.

A large part of the project involved debugging, deployment, UI adjustments, backend integration, and system management. The development process provided practical experience in full-stack application development, deployment workflows, and handling larger project structures.
